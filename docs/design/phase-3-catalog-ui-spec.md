# Phase 3 Catalog UI Spec

## Scope

The catalog UI is an operational local management area, not a marketing screen. It exposes a hub plus service and product flows.

## Screens

- Catalog hub with two actions: Services and Products.
- Active services list.
- Inactive services list.
- Service detail.
- Service create/edit form.
- Active products list.
- Inactive products list.
- Product detail.
- Product create/edit form.

## States

Lists show loading, empty, error, and content states. Forms show field-level validation errors. Detail screens confirm before logical deactivation.

## Controls

- Search field.
- Category text filter.
- Create button.
- Active/inactive toggle via separate route.
- Detail, restore, edit, deactivate actions.

- Do not imply quotes, reports, PDFs, integrations, or calculations exist in Phase 3.
