# Phase 1 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the TechQuote Phase 1 visual shell with design tokens, reusable Compose components, mock navigation, placeholder screens, previews, Android Studio documentation, verification, and a clear commit.

**Architecture:** Keep Routes separate from Screens. Routes own navigation and simulated feedback; Screens receive mock state and callbacks by parameter. UI models and fixtures remain mock-only and do not introduce persistence or business workflows.

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, Navigation Compose, existing Hilt/Room dependencies unused for Phase 1 UI behavior.

---

## File Structure

- `docs/design/phase-1-ui-spec.md`: visual decisions and scope boundary.
- `docs/architecture/navigation-map.md`: route names and back behavior.
- `docs/development/android-studio-preview-and-live-edit.md`: Android Studio, Preview, Emulator, Live Edit, Logcat, and USB device guidance.
- `app/src/main/java/com/techquote/app/ui/theme/*`: design tokens and Material theme.
- `app/src/main/java/com/techquote/app/ui/components/*`: reusable UI components.
- `app/src/main/java/com/techquote/app/ui/model/*`: mock UI state and display models.
- `app/src/main/java/com/techquote/app/ui/previews/*`: grouped preview annotation and deterministic mock fixtures.
- `app/src/main/java/com/techquote/app/ui/{dashboard,clients,catalog,quotes,reports,settings,legal}/*`: Route and Screen composables.
- `app/src/main/java/com/techquote/app/navigation/*`: route constants and NavHost.
- `app/src/test/java/com/techquote/app/navigation/TechQuoteRoutesTest.kt`: route uniqueness tests.
- `CHANGELOG.md`: Phase 1 summary.
- `docs/security/*`: phase close review updates only if real behavior changes.
