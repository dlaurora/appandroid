# TechQuote Overview

TechQuote is starting as a native Android app scaffold.

Current scope:

- Kotlin Android application.
- Jetpack Compose UI.
- Material 3 design components.
- Hilt dependency injection.
- Navigation Compose routing.
- Room dependency setup for future persistence.
- Explicit debug and release build setup.
- Security, privacy, legal, design, and QA guardrails for Phase 0.

Deferred scope:

- Clients.
- Catalog.
- Quotes or budgets.
- Reports.
- PDF generation.
- Backup and import.
- Pricing rules.
- Database schema and domain models.
- External integrations.

## Phase 0 Product Position

Phase 0 creates the technical and governance foundation only. It intentionally avoids business workflows and stores no customer, quote, report, PDF, backup, or catalog data.
