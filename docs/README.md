# TechQuote Documentation

This folder holds product, architecture, design, QA, security, privacy, legal, release, and planning notes for TechQuote.

## Structure

- `project/`: project overview and durable product context.
- `architecture/`: technical stack and design decisions.
- `architecture/decisions/`: Architecture Decision Records.
- `design/`: UX and visual design principles for future phases.
- `qa/`: test strategy and phase verification notes.
- `security/`: threat model, permission register, dependency inventory, and security checklists.
- `legal/`: privacy policy and terms of use drafts.
- `release/`: Google Play and publication readiness drafts.
- `plans/`: incoming plans, pending scope, and implementation notes.

Business functionality is intentionally not specified yet. Add it after the full plan is reviewed.
