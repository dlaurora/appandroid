# Phase 6 Data Handling Review

## Status

Draft only. This is not legal advice and requires qualified professional review before commercial publication.

## Data Added

Phase 6 adds locally stored technical report data:

- client reference
- optional approved quote reference
- technician name
- device/asset text
- problem, diagnosis, work performed, recommendations
- processed image attachments
- generated report PDFs by user action

## User-Controlled Export

PDF save/share/open actions are explicit user actions. Once a PDF is saved outside app storage or shared/opened with another app, TechQuote no longer controls that copy.

## Claims Not Made

Reports and report PDFs do not claim legal, accounting, tax, fiscal, safety, professional certification, or digital signature compliance.
